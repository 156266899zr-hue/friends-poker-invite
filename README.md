# 同桌封闭测试版

本目录以 GitHub `main` 的最新源码快照 `8257463` 为基础，保留卡背皮肤、声音与荷官语音、震动、掉线状态、房间恢复、房主管理、摊牌展示等功能，并加入账号审批和运营后台。

## 本地运行

需要 Node.js 24.7 或以上版本。项目使用 Node 自带的 SQLite 和 Argon2id，无需安装 npm 依赖。

首次运行：

```text
node init-local.mjs
node --env-file=.env server.mjs
```

打开 http://localhost:8787。默认管理员账号为 `156266899`，默认密码为 `888888`。登录后进入「账号设置」，可从默认收起的二级菜单中选择皮肤仓库、修改昵称或修改六位数字密码。

登录只显示账号和密码；切换到注册模式后才显示昵称。新注册账号为待审核状态，管理员确认是朋友后在管理后台批准，才能创建或加入房间。分享房间链接不能绕过账号审核。

`.env` 和 `data/` 已被 Git 忽略。管理员初始配置只在空数据库第一次启动时生效，不会覆盖已修改的密码。

## 最新版功能保留情况

- 四款卡背：经典墨绿、象牙鎏金、午夜星辰、东方水墨。卡背保存在账号中，换设备或重新登录后仍会同步。
- 七个录制语音文件分别用于过牌、跟注、加注、全下、弃牌、轮到玩家和摊牌；保留声音、语音、音量和震动设置。
- 刷新或重新登录后恢复原房间，账号与牌桌座位绑定。
- 玩家在线状态、房主移出玩家、对局中标记本手结束后移出。
- 结算时显示公共牌、摊牌玩家底牌和赢家。
- 行动提醒、计时警告、牌局历史和移动端布局。
- 管理后台按钮只向管理员显示。退出账号只在大厅主页显示，进入牌桌后隐藏。
- 管理员审批、封禁、撤销登录、关闭房间、注册上限、在线用户与审计记录；用户管理和近期记录使用默认收起的二级菜单。

后台不显示底牌或任何登录凭证。封禁或撤回审批会撤销登录并关闭该账号所在房间。账号准入和记录不能自动判断场外结算，批准前仍需通过认识的联系方式核实身份。

## 数据与部署

账号、密码哈希、审批状态、会话、注册上限和审计记录保存在 `data/accounts.sqlite`。房间与进行中的牌局仍在内存中，服务重启会关闭房间，但账号数据保留。

本地预览默认只监听 `127.0.0.1`。同一 Wi-Fi 手机测试时，将 `HOST` 改为 `0.0.0.0`，并把 `PUBLIC_ORIGIN` 改为实际局域网地址。公网部署必须设置正式 HTTPS 域名、`COOKIE_SECURE=true`、持久化数据目录和异机备份，并由反向代理提供 HTTPS。

腾讯云部署应固定使用经过测试的 GitHub 提交，并配置正式 HTTPS 域名、持久化数据卷和备份。服务器地址与登录方式准备好后，可从同一提交继续部署。
